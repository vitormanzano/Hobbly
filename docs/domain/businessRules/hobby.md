# Business Rules for Hobby

- BR15: A hobby suggested by a user must be approved by an admin before becoming available on the platform.
- BR16: A rejected hobby suggestion is permanently discarded.
- BR17: Only an admin can approve or reject hobby suggestions.
- BR18: When adding a hobby to a profile, the user must inform a practice time from the fixed scale: Less than 6 months, Less than 1 year, 1 year, 2 years, 3 years, 4 years, 5+ years, 10+ years.
- BR19: Removing a hobby from a profile does not delete the hobby from the platform.
